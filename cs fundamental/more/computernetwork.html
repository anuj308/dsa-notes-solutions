1. Basics & Network Topologies

What is a Computer Network?

A system of interconnected computing devices that communicate over wired or wireless links to exchange data, share resources, and deliver services using a well-defined set of protocols.

Objectives

  • Resource Sharing – hardware, software, data
  • Communication – email, messaging, video conferencing
  • Reliability – backup paths, fault tolerance
  • Scalability – easy expansion as users grow
  • Cost Efficiency – shared infrastructure reduces costs

Fundamental Components

  • Sender – device that generates data
  • Receiver – device that receives data
  • Message – information being transmitted
  • Transmission Medium – physical or wireless path
  • Protocol – set of rules governing communication

Network Topologies

Mesh – every device connected to every other; N(N−1)/2 links; high fault tolerance, expensive. Bus – single backbone cable; simple, cheap, but less reliable. Star – central hub/switch; easy to manage; central failure brings down network. Ring – closed loop; data travels in one direction; failure of one device disrupts.

Mesh Bus Star Ring

Transmission Modes

  • Simplex – one-way only (e.g., TV broadcast).
  • Half-duplex – both can transmit, but not simultaneously (e.g., walkie-talkie).
  • Full-duplex – simultaneous two-way (e.g., telephone).

2. OSI & TCP/IP Models

OSI Model (7 layers)

  1. Physical – raw bit transmission over medium.
  2. Data Link – framing, error control, MAC addressing.
  3. Network – logical addressing, routing, packet forwarding.
  4. Transport – end-to-end communication, segmentation, flow control.
  5. Session – establishes, manages, and terminates sessions.
  6. Presentation – data translation, encryption, compression.
  7. Application – network services to end-user applications.

Developed by ISO in 1984

TCP/IP Model (4 layers)

  1. Application – combines OSI layers 5,6,7; protocols: HTTP, FTP, SMTP, DNS.
  2. Transport – TCP (reliable) and UDP (fast).
  3. Internet – IP addressing, routing (IPv4/IPv6).
  4. Network Access (Link) – physical and data link functions.

Developed by DARPA Used on the Internet

3. Physical Layer

Responsibilities

  • Bit transmission over physical medium
  • Defines voltage levels, data rate, bit synchronization
  • Line configuration (point-to-point / multipoint)
  • Physical topology & transmission modes

Transmission Media

Guided (Wired)

  • Twisted Pair – low cost, LANs
  • Coaxial Cable – better noise resistance, cable TV
  • Optical Fiber – very high speed, long distance

Unguided (Wireless)

  • Radio Waves – Wi-Fi, Bluetooth
  • Microwaves – cellular, satellite
  • Infrared – short-range communication

4. Data Link Layer

Functions

  • Framing – divides raw bit stream into frames
  • Error Control – detection & correction (Hamming, CRC, Checksum)
  • Flow Control – prevents sender from overwhelming receiver
  • Medium Access Control (MAC) – controls access to shared medium
  • Physical Addressing – uses MAC addresses

Basic Time Delays

Transmission Delay (Td) = Length of packet / Bandwidth
Propagation Delay (Pd) = Distance / Propagation speed
Round Trip Time (RTT) = time for frame to reach receiver + ACK to return

Flow Control Protocols

  • Stop-and-Wait – one frame at a time; simple but low utilization.
  • Go-Back-N ARQ – cumulative ACK; sender window = 2k − 1; receiver window = 1.
  • Selective Repeat ARQ – retransmits only lost frames; more efficient, higher buffer.
Efficiency (Go-Back-N) = N × Td / (Td + 2Pd + Qd + Prd + Td(ACK))

MAC Protocols

  • ALOHA – pure & slotted
  • CSMA/CD – Ethernet, detects collisions
  • CSMA/CA – Wi-Fi, avoids collisions (RTS/CTS)
  • Token Passing – token circulates; only token holder transmits

Error Detection

  • Hamming Code: 2r ≥ m + r + 1 (r = redundant bits, m = data bits)
  • CRC – polynomial division
  • Checksum – sum of data words

5. Network Layer

IPv4 Datagram Header (key fields)

  • Version (4 bits) – 4 for IPv4
  • HLEN – header length in 32-bit words (min 5, max 15)
  • Total Length – header + data (min 20 bytes, max 65535)
  • Identification – unique packet ID for fragmentation
  • Flags – reserved, don't fragment, more fragments
  • Fragment Offset – position of fragment in original datagram
  • Time to Live (TTL) – max hops
  • Protocol – TCP (6), UDP (17), ICMP (1)
  • Header Checksum – error detection for header
  • Source & Destination IP – 32 bits each

Subnetting

Dividing a large network into smaller logical subnets. Improves security, performance, and IP utilization.

Example: 192.168.1.0/24 → create 4 subnets.
2n ≥ 4 → n = 2. New prefix = /26 (255.255.255.192).
Each subnet: 64 addresses, 62 usable.
  • Subnet 1: 192.168.1.0 – 192.168.1.63
  • Subnet 2: 192.168.1.64 – 192.168.1.127
  • Subnet 3: 192.168.1.128 – 192.168.1.191
  • Subnet 4: 192.168.1.192 – 192.168.1.255

Supernetting

Combining multiple smaller networks into a larger one (route summarization). Reduces routing table size.

VLSM

Variable Length Subnet Mask – allows different subnet masks within the same network, reducing IP wastage.

ICMP

Used for error reporting and diagnostics (ping, traceroute). Messages: Destination Unreachable, Time Exceeded, Echo Request/Reply.

Routing

  • Distance Vector Routing (DVR) – Bellman-Ford, hop count metric (RIP). Suffers from count-to-infinity.
  • Link State Routing (LSR) – Dijkstra, OSPF. Fast convergence, no count-to-infinity.

ARP & RARP

  • ARP – maps IP → MAC address within a LAN.
  • RARP – maps MAC → IP address (diskless workstations).

6. Transport Layer

TCP (Transmission Control Protocol)

  • Connection-oriented, reliable, in-order delivery.
  • Uses sequence numbers, ACKs, retransmissions.
  • Flow control & congestion control (slow start, congestion avoidance).
  • Minimum header 20 bytes.
  • 3-Way Handshake: SYN → SYN-ACK → ACK
  • Connection Termination: FIN, ACK-FIN, etc.

UDP (User Datagram Protocol)

  • Connectionless, unreliable, fast.
  • No ACKs, no retransmission.
  • Fixed 8-byte header.
  • Used for DNS, VoIP, video streaming, online games.

7. Session, Presentation & Application Layers

Session Layer (Layer 5)

  • Establishes, manages, and terminates sessions.
  • Dialog control, synchronization (checkpoints).
  • Example: logging into a remote server.

Presentation Layer (Layer 6)

  • Data translation (ASCII ↔ Unicode, EBCDIC ↔ ASCII).
  • Encryption/decryption, compression/decompression.
  • Ensures interoperability between different systems.

Application Layer (Layer 7)

  • Provides network services to end-user applications.
  • Protocols: HTTP/HTTPS, FTP/SFTP, SMTP, POP3, IMAP, DNS, DHCP.
  • Supports email, file transfer, web browsing, name resolution.

11. Security & VPN

  • VPN – secure, encrypted tunnel over public network; masks IP.
  • SSL/TLS – encryption for HTTPS, secure communication.
  • Firewall – monitors and controls traffic.
  • IDS/IPS – intrusion detection / prevention.
  • DMZ – buffer zone for external-facing services.
  • QoS – prioritizes critical traffic (VoIP, video).
  • Load Balancing – distributes traffic across servers.
  • Port Forwarding – directs external traffic to internal hosts.

12. Frequently Asked Interview Questions

What is the OSI model?

A 7-layer framework: Physical, Data Link, Network, Transport, Session, Presentation, Application. Each layer has specific functions.

TCP vs UDP?

TCP: connection-oriented, reliable, slower. UDP: connectionless, fast, no reliability. TCP for web/email, UDP for streaming/gaming.

What is subnetting?

Dividing a network into smaller subnets to improve performance, security, and IP utilization.

Difference between router and switch?

Router: connects networks (Layer 3), uses IP. Switch: connects devices within a LAN (Layer 2), uses MAC.

What is DNS?

Translates domain names (www.google.com) to IP addresses. Works like a phonebook for the internet.

What is DHCP?

Automatically assigns IP addresses to devices on a network.

What is NAT?

Maps private IPs to a public IP, allowing multiple devices to share one public IP.

What is ARP?

Resolves IP address to MAC address within a local network.

What is ICMP used for?

Error reporting and diagnostics (ping, traceroute).

Explain VLAN.

Virtual LAN – logically groups devices on the same physical switch into separate broadcast domains.

What is the difference between HTTP and HTTPS?

HTTPS is HTTP with SSL/TLS encryption, ensuring secure data transmission.

What is a firewall?

Security device/software that filters traffic based on rules.

13. Classic Scenario: What happens when you type www.google.com?

  1. DNS lookup – browser checks cache, then queries DNS server to get Google's IP.
  2. HTTP request – browser creates an HTTP GET request using TCP/IP.
  3. Routing – packets travel through routers across the internet.
  4. Server response – Google's server processes the request and sends back the webpage.
  5. Rendering – browser renders HTML, CSS, JS, and displays the page.

DNS → TCP/IP → Routing → Response → Render
