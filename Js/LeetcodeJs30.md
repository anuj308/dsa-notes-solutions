## Day 1: Create Hello World Function

- **Problem Link**: [Create Hello World Function](https://leetcode.com/problems/create-hello-world-function/)
- **Difficulty**: Easy

### Solution

```javascript
/**
 * @return {Function}
 */
var createHelloWorld = function() {
    
    return function(...args) {  
        return "Hello World";
    }
};

/**
 * const f = createHelloWorld();
 * f(); // "Hello World"
 */
```
