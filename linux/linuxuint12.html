🔗 Hard Link vs Soft Link (VIVA Question!)

Hard Link

  • Same inode number as original file
  • Point directly to data
  • Works even if original is deleted
  • Cannot cross filesystems
  • Cannot link directories
ln file1 file2 # Create hard link

Soft Link (Symbolic)

  • Different inode number
  • Stores path to original (shortcut)
  • Breaks if original is deleted
  • Can cross filesystems
  • Can link directories
ln -s file1 link1 # Create soft link

UNIT II Permissions, Processes, Services & SSH

🔐 File Permissions (VIVA Focus!)

rwx r-x r-- = owner(7) group(5) others(4)

  • Read (r) = 4 | Write (w) = 2 | Execute (x) = 1
  • File: r=view content, w=edit, x=execute
  • Directory: r=list files, w=create/delete files, x=cd into directory
CommandPurposeExample
chmodChange permissionschmod 755 file.sh / chmod u+x file
chownChange ownerchown user:group file.txt
chgrpChange groupchgrp developers file.txt
umaskDefault permissionsumask 022 → files:644, dirs:755
ls -lView permissionsls -l file

⚡ Special Permissions

PermissionEffect on FileEffect on Directory
SUID (u+s)Run as file ownerNo effect
SGID (g+s)Run as group ownerNew files inherit directory's group
Sticky (o+t)No effectOnly file owner can delete their files
chmod u+s file chmod g+s dir chmod o+t dir # Examples

⏰ Cron Jobs (Scheduling)

Cron format: minute hour day month weekday command

* * * * * echo "Hello" >> /tmp/cron_test.txt # Every minute
CommandPurpose
crontab -eEdit cron jobs
crontab -lList jobs
crontab -rRemove all jobs

Examples:

0 2 * * * /backup.sh # Daily at 2 AM
30 8 * * 1-5 /script.sh # Weekdays 8:30 AM

🔌 SSH (Secure Shell)

  • Encrypted remote access
  • Default port: 22
ssh user@remotehost # Connect to remote
ssh-keygen -t rsa # Generate SSH key pair
ssh-copy-id user@remotehost # Copy public key for passwordless login
