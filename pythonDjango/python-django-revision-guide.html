Ubuntu — Install Python & Django

▼

Everything you need to type in the terminal. Open terminal with Ctrl + Alt + T.

1. Check if Python is installed

terminal
python3 --version      # e.g. Python 3.12.3
sudo apt update        # if it is not installed, run:
sudo apt install python3 python3-pip

2. Create a virtual environment (best practice!)

terminal
cd ~/Desktop/work            # go to your project folder
python3 -m venv myenv        # create virtual env named "myenv"
source myenv/bin/activate    # turn it ON  (you will see (myenv) in prompt)
deactivate                   # turn it OFF
💡
A virtual environment keeps your project's packages separate. Always activate it before installing or running anything for your project.

3. Install Django

terminal
pip install django          # installs latest Django
django-admin --version      # check it worked, e.g. 5.x
pip freeze                  # see all installed packages

4. Create a project & run it

terminal
django-admin startproject myproject   # one project = one website
cd myproject
python manage.py startapp myapp        # one app = one feature inside it
python manage.py runserver             # start the server
# open http://127.0.0.1:8000 in your browser
🧭
Project vs App: a project is the whole website (settings, urls). An app is a feature inside it (e.g. blog, shop, users). One project can have many apps.

Quick reference — files Django creates

FileWhat it does
manage.pyYour command center (runserver, migrate, etc.)
settings.pyProject settings — apps, database, timezone, templates
urls.pyMaps web addresses to views
views.pyPython functions that handle requests
models.pyYour database tables written in Python
admin.pyRegister models for the admin panel

Strings

▼

Text in Python. Indexing starts at 0 — this trips everyone up at first!

Creating strings

python
s1 = "hello"          # double quotes
s2 = 'world'          # single quotes — same thing
s3 = """multi
line
text"""               # triple quotes for long text
s4 = "he said \"hi\"" # escape a quote with backslash

Indexing & slicing (position numbers)

python
word = "python"
#       012345   ← positions (starts at 0)
word[0]      # 'p'
word[3]      # 'h'
word[-1]     # 'n'   negative = from the end
word[0:3]    # 'pyt'  start:stop (stop NOT included)
word[:3]     # 'pyt'  from start
word[3:]     # 'hon'  to the end
word[::2]    # 'pto'  step of 2
len(word)    # 6     number of characters
💡
Slicing rule: word[start:stop] gives you items from start up to but not including stop. This rule applies to lists too.

Handy string methods

python
s = "  Hello World  "

s.lower()        # '  hello world  '
s.upper()        # '  HELLO WORLD  '

s.split()        # ['Hello', 'World']  (split on spaces)
s.split(",")     # split on any character you give
"-".join(["a","b","c"])   # 'a-b-c'
s.find("World")  # 8   position, or -1 if not found
s.count("l")     # 3
s.startswith("  ")  # True
"abc" in s       # False
"World" in s     # True

Combine strings

python
"Hello" + " " + "World"   # 'Hello World'
"ha" * 3                    # 'hahaha'
f"2 + 2 = {2+2}"            # '2 + 2 = 4'   ← f-string, use this

Lists

▼

An ordered, changeable collection: [a, b, c]. You'll use lists every single day.

python
fruits = ["apple", "banana", "cherry"]

fruits[0]          # 'apple'  (first item)
fruits[-1]         # 'cherry' (last item)
len(fruits)        # 3

fruits.append("mango")     # add at the END
fruits.insert(1, "kiwi")   # insert at position 1
fruits.remove("banana")    # remove by value
last = fruits.pop()        # remove & return last item
fruits[0] = "grape"        # change an item

"apple" in fruits  # True   (check if something is inside)

fruits.sort()      # sort in place
fruits.reverse()   # reverse in place
sorted(fruits)     # returns a NEW sorted list (doesn't change it)

Looping over a list (see section 8 for more)

python
for fruit in fruits:
    print(fruit)

Copying a list — careful!

python
a = [1, 2, 3]
b = a            # ❌ b is NOT a copy — both point to the SAME list
b.append(4)
print(a)         # [1, 2, 3, 4]  ← a changed too!

b = a[:]         # ✅ copy the whole list
b = a.copy()     # ✅ also works

Tuples, Sets & Dictionaries

▼

Tuple — like a list, but can't change

python
point = (3, 4)
point[0]         # 3
# point[0] = 5   # ❌ ERROR — tuples are fixed

x, y = point     # unpacking — very handy!
# x = 3, y = 4

a, b = b, a      # swap two variables with one line!

Set — unique items only, no order

python
s = {1, 2, 2, 3, 3, 3}
print(s)             # {1, 2, 3}  ← duplicates removed
s.add(4)
s.remove(1)
{1, 2} | {2, 3}      # {1, 2, 3}  union
{1, 2} & {2, 3}      # {2}       intersection
{1, 2} - {2}         # {1}       difference

Dictionary — key → value pairs (super important in Django!)

python
student = {
    "name": "Alice",
    "age": 20,
    "subjects": ["Math", "CS"],
}

student["name"]        # 'Alice'  (get by key)
student.get("age")     # 20
student.get("grade", "not set")   # 'not set' (safe default)

student["age"] = 21    # change value
student["city"] = "Pune"   # add new key
del student["city"]    # delete a key

student.keys()         # dict_keys(['name', 'age', 'subjects'])
student.values()       # values only
student.items()        # pairs of (key, value)

"name" in student      # True  (checks KEYS, not values)

Looping a dictionary

python
for key in student:          # keys only
    print(key)

for key, value in student.items():
    print(f"{key} = {value}")
🧭
In Django, dictionaries flow everywhere: a view sends a dictionary of data to a template, and templates read it with {{ key }}. Know your dicts!

if / elif / else

▼

Indentation is everything in Python. Code inside a block must be indented (4 spaces). Forgetting it = IndentationError.

python
marks = 75

if marks >= 90:
    print("Grade A")
elif marks >= 75:          # "else if"
    print("Grade B")
elif marks >= 60:
    print("Grade C")
else:                      # everything else
    print("Fail")

# 75 → prints "Grade B"

Truthiness — what counts as False?

python
# These are all FALSY (act like False):
0, 0.0, "", [], {}, (), None

if []:            # empty list → False → skipped
    print("never printed")
if "text":        # non-empty → True
    print("always printed")

if not name:      # common pattern: name is empty string
    print("Name is required!")

Short "ternary" if — one line

python
age = 17
status = "adult" if age >= 18 else "minor"
print(status)    # minor

Loops

▼

for loop — the one you'll use 90% of the time

python
for i in range(5):       # 0,1,2,3,4  (starts at 0!)
    print(i)

for i in range(1, 6):    # 1,2,3,4,5  (start, stop)
    print(i)

for i in range(0, 10, 2):  # 0,2,4,6,8  (step)
    print(i)
⚠️
range(5) gives 0 to 4, not 1 to 5. The stop number is never included — same rule as slicing!

Looping over collections

python
for fruit in ["apple", "banana"]:
    print(fruit)

for ch in "abc":          # strings are iterable too
    print(ch)

for i, fruit in enumerate(["apple", "banana"]):
    print(i, fruit)       # 0 apple / 1 banana  (index + value)

while loop

python
count = 0
while count < 3:
    print(count)
    count += 1     # ← MUST update, or infinite loop!

# break   → exit the loop immediately
# continue → skip to the next round
for i in range(10):
    if i == 3:
        continue        # skip 3
    if i == 7:
        break           # stop at 7
    print(i)            # 0,1,2,4,5,6

Nested loops (loop inside a loop)

python
for row in range(1, 4):
    for col in range(1, 4):
        print(f"({row},{col})", end=" ")
    print()   # new line after each row

Sum with a loop

python
total = 0
for n in [5, 10, 15]:
    total += n
print(total)   # 30   (same as sum([5, 10, 15]))

Functions

▼

A function is a reusable block of code: def name(parameters):. Django views are just functions — master this!

Basic function

python
def greet(name):
    print(f"Hello, {name}!")

greet("Alice")        # Hello, Alice!
greet("Bob")          # Hello, Bob!

Returning a value

python
def add(a, b):
    return a + b        # return = send the result back

result = add(3, 5)      # result is now 8
print(result)

def is_even(num):
    return num % 2 == 0

print(is_even(10))      # True
print(is_even(7))       # False

Default & keyword arguments

python
def greet(name, greeting="Hello"):
    print(f"{greeting}, {name}!")

greet("Alice")                # Hello, Alice!  (default used)
greet("Bob", "Hi")            # Hi, Bob!
greet(name="Sam", greeting="Hey")   # keyword order doesn't matter

*args and **kwargs — any number of arguments

python
def total(*numbers):       # *args → tuple of all extra values
    return sum(numbers)

print(total(1, 2, 3))      # 6
print(total(10, 20))       # 30

def show(**info):          # **kwargs → dictionary
    for key, value in info.items():
        print(f"{key}: {value}")

show(name="Alice", age=20)   # name: Alice / age: 20

lambda — a tiny one-line function

python
square = lambda x: x * x
print(square(5))           # 25

# same as:
def square(x):
    return x * x

Scope — inside vs outside

python
total = 0                       # global variable

def add_ten(n):
    total = n + 10              # local — different variable!
    return total

print(add_ten(5))               # 15
print(total)                    # 0  (global unchanged)

List Comprehensions

▼

A shortcut to build a list in one line. Pattern: [expression for item in list if condition]

python
# squares of 0..4
squares = [x * x for x in range(5)]
print(squares)              # [0, 1, 4, 9, 16]

# even numbers only
nums = [1, 2, 3, 4, 5, 6]
evens = [n for n in nums if n % 2 == 0]
print(evens)                # [2, 4, 6]

# uppercase a list of words
words = ["hi", "bye"]
upper = [w.upper() for w in words]
print(upper)                # ['HI', 'BYE']

# same thing with a normal loop (long way):
evens2 = []
for n in nums:
    if n % 2 == 0:
        evens2.append(n)
💡
Read it aloud: "make a list of x*x for each x in range(5)". You can also make dict comprehensions: {k: v for ...}.

Error Handling (try / except)

▼

Errors happen. try the risky code, except catches the problem instead of crashing.

python
try:
    age = int(input("Enter your age: "))
    print(10 / age)
except ValueError:              # input was not a number
    print("That's not a number!")
except ZeroDivisionError:       # age was 0
    print("Can't divide by zero!")
except Exception as e:          # catch anything else
    print("Something went wrong:", e)
else:
    print("No errors!")         # runs only if NO error
finally:
    print("Always runs")        # runs no matter what

Common built-in errors

ErrorWhen it happens
ValueErrorWrong value, e.g. int("abc")
TypeErrorWrong type, e.g. "5" + 5
ZeroDivisionErrorDividing by zero
IndexErrorList index out of range
KeyErrorDict key doesn't exist
NameErrorVariable not defined
FileNotFoundErrorOpening a file that isn't there

Raising your own errors

python
def set_age(age):
    if age < 0:
        raise ValueError("Age can't be negative!")
    return age

Working with Files

▼

Always use with open(...) — it closes the file for you automatically.

python
# WRITE (creates or overwrites the file)
with open("notes.txt", "w") as f:
    f.write("Hello file!\n")
    f.write("Second line\n")

# READ the whole file
with open("notes.txt", "r") as f:
    content = f.read()
print(content)

# READ line by line
with open("notes.txt", "r") as f:
    for line in f:
        print(line.strip())   # strip removes the \n

# APPEND (adds to the end, doesn't overwrite)
with open("notes.txt", "a") as f:
    f.write("More text\n")

File modes

ModeMeaning
"r"Read (default). Error if file missing
"w"Write — overwrites everything
"a"Append — add to the end
"r+"Read AND write
"x"Create only if it doesn't exist

OOP — Classes & Objects

▼

A class is a blueprint; an object is one thing made from it. Django models are classes — you need this!

Create a class

python
class Student:
    def __init__(self, name, age):
        self.name = name        # attribute
        self.age = age

    def introduce(self):        # method = function inside a class
        print(f"I'm {self.name}, {self.age} years old")

s1 = Student("Alice", 20)       # create an object
s2 = Student("Bob", 19)

s1.introduce()                  # I'm Alice, 20 years old
print(s1.name)                  # Alice
💡
__init__ runs automatically when you create an object. self = "this object". Every method must take self as its first parameter.

Inheritance — a class based on another class

python
class Person:
    def __init__(self, name):
        self.name = name
    def speak(self):
        print(f"{self.name} speaks")

class Teacher(Person):          # Teacher inherits from Person
    def __init__(self, name, subject):
        super().__init__(name)  # call the parent's __init__
        self.subject = subject
    def teach(self):
        print(f"{self.name} teaches {self.subject}")

t = Teacher("Dr. Sharma", "Python")
t.speak()       # inherited method → Dr. Sharma speaks
t.teach()       # own method → Dr. Sharma teaches Python
isinstance(t, Person)   # True

Special dunder methods (double underscore)

python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):          # what print() shows
        return f"Point({self.x}, {self.y})"

    def __add__(self, other):   # what + does
        return Point(self.x + other.x, self.y + other.y)

p1 = Point(1, 2)
p2 = Point(3, 4)
print(p1)            # Point(1, 2)  ← via __str__
print(p1 + p2)       # Point(4, 6)  ← via __add__

Django Basics — the Full Flow

▼

How a request travels: URL → View → Template. Data flows: Model → Database. Learn this loop and you understand Django.

🌐
The request cycle: browser hits /about → Django checks urls.py → finds a matching path → calls the view → view does logic and calls render() → template HTML is sent back.

1. Views — a Python function that returns a response

python
# myapp/views.py
from django.shortcuts import render
from django.http import HttpResponse

def home(request):                       # request = browser's request
    return HttpResponse("Hello, world!") # plain text reply

def about(request):
    return render(request, "about.html") # reply with a template

def greet(request, name):                # captured from the URL
    context = {
        "name": name,
        "age": 20,               # demo data for the template
        "fruits": ["apple", "banana"],
    }
    return render(request, "greet.html", context)

2. URLs — wire addresses to views

python
# myapp/urls.py  (you create this file)
from django.urls import path
from . import views

urlpatterns = [
    path("", views.home, name="home"),        # /  (home page)
    path("about/", views.about, name="about"),
    path("greet/<str:name>/", views.greet, name="greet"),
]
python
# myproject/urls.py  (the project's urls — add your app)
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path("admin/", admin.site.urls),
    path("", include("myapp.urls")),   # include your app's urls
]

8. Forms — getting data from the user

# views.py — handle a POST request
def add_student(request):
    if request.method == "POST":
        name = request.POST["name"]     # data from the form
        age = request.POST["age"]
        Student.objects.create(name=name, age=age)
        return redirect("students_list")
    return render(request, "add_student.html")
